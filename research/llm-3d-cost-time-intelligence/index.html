How the axes are defined. Intelligence = Artificial Analysis Intelligence Index (composite). Cost and time each have two selectable metrics, all of which point the same way (lower is better).

Cost metric. $ per task (AA) is the weighted average USD per Intelligence Index task from AA's chart. $ per M tokens (OpenRouter, blended) is OpenRouter's list price with input and output blended 3:1 (the AA convention: (3 × input + output) ÷ 4), so it ignores how many tokens a model burns per task. Step 5 Preview is not on OpenRouter, so its AA list price is used. Both are log scales.

Time metric. The three tok/s options turn output speed into seconds per 1,000 output tokens (1000 ÷ tok/s): AA chart is read off Artificial Analysis' Intelligence vs Output Speed chart, while OpenRouter p50 and p90 are the median and 90th-percentile tokens per second OpenRouter reported for each model over its last 30-minute window, averaged across providers weighted by request count, as of 4 Oct 2026. Step 5 Preview is not listed on OpenRouter, so it keeps its AA chart speed in those modes. Time per task (AA) is AA's wall-clock seconds per Intelligence Index task, which includes how many tokens a model spends and how long it thinks. Each metric resets its threshold slider to a sensible default.

Caveat. Intelligence and per-task cost were read off the Artificial Analysis charts, so they are approximate, probably within a point of index and a few percent of cost. Only models that appear in both AA charts are plotted. The tok/s time options are a speed-based proxy, not end-to-end task time; use time per task for that. Default octant thresholds are my choice and are adjustable above.
