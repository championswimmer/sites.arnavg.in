Intelligence vs Cost vs Time

A 3D take on Artificial Analysis' two 2D charts. Every model is placed by Intelligence Index, cost per task and response time. The green octant is the corner where cost is lowest, time is lowest and intelligence is highest. Drag to rotate, scroll to zoom, hover for details.

How the axes are defined. Intelligence = Artificial Analysis Intelligence Index (composite). Cost = weighted average USD per Intelligence Index task (log scale, as in AA's chart). Time = seconds to generate 1,000 output tokens, i.e. 1000 ÷ output tokens per second, so lower is better and it points the same way as cost.

Speed data (OpenRouter, 4 Oct 2026). Output speed is the p90 tokens per second that OpenRouter reported for each model over its last 30-minute window: 90% of requests ran at or below this speed, so it reflects the fast end of what you typically get rather than the middle. It is averaged across the model's providers, weighted by each provider's request count. These are average values as of 4 Oct 2026 and shift through the day. Step 5 Preview is not listed on OpenRouter, so it keeps the speed read off the Artificial Analysis chart (not a p90 figure). Muse Glimmer is matched to OpenRouter's meta/muse-glimmer-30b, and Qwen3.8 Max to qwen/qwen3.8-max-0902.

Caveat. Intelligence and cost were read off the Artificial Analysis charts (Intelligence vs Cost per task), so they are approximate, probably within a point of index and a few percent of cost. Only models that appear in both AA charts are plotted. Time is a speed-based proxy, not end-to-end task time, which would also depend on how many tokens each model spends per task.
