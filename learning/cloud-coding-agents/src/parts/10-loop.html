Your session runs on a VM, not just chat.

Plan: reads the ticket + the repo. Needs ticket access and repo read.

Act: edits, runs, calls tools. Needs repo write (clone), shell, MCP.

Observe: reads results back. Needs logs, exits, CI output.

Repair: reproduces on a staging-like env. Needs staging / prod-ish access to debug, then loops back to Act.

Handoff: ships it. Needs raise PR, link ticket, deploy access.

Each highlighted box needs a permission. Watch this space.

Walk the five clicks slowly. Plan: the model reads the ticket and the code — that step already needs ticket access plus repo read. Act: it edits files, runs commands, calls tools — needs repo write, a shell, MCP. Observe: needs logs, exit codes, CI output flowing back. Repair: it reproduces against a staging-like environment — needs staging or prod-ish access to debug — then follows the loopback arrow into Act again. Handoff only happens when acceptance checks pass, and needs permission to raise a PR, link the ticket and deploy. The punchline to land: every one of those verbs needs a real machine.

Code is how your agent gets things done.

One script replaces dozens of tool calls.

Your model already knows bash, Python, pytest.

Your files and servers stay live between steps.

You ship a tested patch, not a guess.

Code mode means the model may write and execute code instead of only chatting. Click through the four commands. Why it wins: code is compact — one script with loops and retries replaces dozens of tool calls. It reuses model priors — bash, Python, Playwright are already known. And state persists — the shell keeps variables, files and servers across iterations. Land on the verified diff: the output is proven by execution, not asserted.

Without in-loop verification, agents optimise for plausible-looking diffs. Click through the three gates: lint and typecheck catch static errors in seconds, the build catches integration breakage, tests and browser checks catch runtime failures. Each gate stops error compounding over long runs. The contrast at the bottom is the sentence to say out loud: no run, no trust.
