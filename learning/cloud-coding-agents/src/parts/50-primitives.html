This example restores files, not running processes.

Snapshots are just files in object storage.

A read-only base plus a writable layer keeps edits separate.

Each sandbox gets one owner that outlives its container.

A backup stores a directory archive and metadata in R2. Restore fetches them and adds a writable layer. That is slower than keeping a live local disk, but it survives the container being replaced. A Durable Object coordinates the sandbox and can persist session metadata. Applications must choose what to save.
