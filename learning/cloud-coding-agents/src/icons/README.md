# Vendored deck icons

These SVGs are downloaded assets, not redrawn approximations. They are local build
inputs for inline SVGs; no runtime fetching is needed. Original `viewBox`
values and geometry are preserved. Lucide retains `fill="none"` and
`stroke="currentColor"`; monochrome brands use `fill="currentColor"` (including
Devicon AWS's originally orange plain wordmark). Simple Icons titles are retained.

## Official assets for missing brands

Daytona and E2B were not in the checked icon packs. Their genuine brand assets
are vendored directly, without changing geometry or viewBox:

- `brand-daytona.svg`: inline wordmark from https://www.daytona.io/docs/
  (the `daytona-logo` navigation link). Brand guidelines: https://www.daytona.io/brand
- `brand-e2b.svg`: https://e2b.dev/brand/e2b-symbol-white-s.svg
  Brand guidelines: https://e2b.dev/brand

These official assets remain subject to their owners' rights and brand guidelines;
they are not covered by the icon-pack licenses above. No open-source license is
claimed for them. E2B keeps its original white fill. Daytona uses currentColor.

Fly.io uses Simple Icons' `flydotio` slug. AWS uses Devicon because the checked
Simple Icons release does not include `amazonwebservices`.

## Validation

All 41 SVG files were parsed with Python's `xml.etree.ElementTree`, checked for
an SVG root and an unchanged source `viewBox`, and checked for the expected
fill/stroke (currentColor in the icon packs, original colours in official assets). No scripts, embedded images, or foreignObject elements
are included. Only these local files are required by the deck build.
