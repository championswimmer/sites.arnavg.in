Pi's agent loop. Each stage fires named, typed events.

Input: the prompt arrives. The run hasn't started yet.

Context: a turn starts; you can rewrite what the model sees.

Provider: headers, the raw request payload, the response.

Stream: one message_update per delta.

Tool calls: inspect, patch or block before execution.

Tool results: patch the output before the model reads it.

Tools ran, so the loop goes round again.

Turn 1: the model sees the results and answers in text.

No tool calls: turn_end → agent_end → agent_settled.

14 of 36 events take a return value ✎. Handlers chain in load order.

[~1:30] Same loop, real event names. Click any chip → payload + what it can return.

  • 1 Input: input can transform or swallow the prompt; before_agent_start can inject a message or swap this run's system prompt
  • 2 Context: deep copy of messages before every LLM call. Rewrite it → model sees something else; session file untouched
  • 3 Provider: before_provider_request can see / replace the exact payload
  • 4 Stream: message_end can replace the final message before it's saved
  • 5 Tool calls: after validation, before execute → this is where you block
  • 6 Tool results: patch output before the model reads it
  • 7–9: tools ran → loop; turn 1 answers in text → ends
  • 10: two kinds of hook: observe (return nothing) vs intervene (return a value)
    • 14 of 36 events can intervene; 8 are on this loop
    • Handlers awaited one at a time, in load order; changes chain. tool_call: first block wins
    • A slow handler slows the loop, even on message_update

what is an extension?

One file. One function. It gets pi.

~/.pi/agent/extensions/hello.ts (illustrative)

import type { ExtensionAPI } from "@earendil-works/pi-coding-agent"; export default function (pi: ExtensionAPI) { pi.on("turn_end", (event, ctx) => { ctx.ui.setStatus("turns", `turn ${event.turnIndex + 1}`); }); pi.registerTool({ name: "roll_dice", /* … */ }); pi.registerCommand("hello", { /* … */ }); }
drop it in~/.pi/agent/extensions/or.pi/extensions/then/reload
